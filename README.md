# AMD DLSS 5 助手（源码预览）

这是一个中文 Windows 图形助手，负责：选择游戏目录、释放内置的 `nvngx_dlssnr.dll`、下载并核对官方 `dlssnr_on_amd_setup.exe`，再把两份文件安全准备到游戏 EXE 目录、启动官方安装器，并提供准备阶段的恢复功能。

## 关键边界

上游项目的安装器和代理 DLL 未公开源代码，并且其许可证禁止把上游安装器重新打包、修改或嵌入其他工具。本项目不复制或修改上游安装器；内置 DLL 来自用户提供的文件，仅用于该用户自己的私有构建和测试，发布前必须确认自己拥有相应的再分发权。官方安装器仍在运行时从官方 GitHub API 下载并校验。

当前官方说明：Windows 11、DX12 + FSR、Adrenalin 26.1.1+；主要测试 RX 9000，RX 7000 需要自行验证；游戏内按 End 打开覆盖层。上游项目说明安装器位于游戏 EXE 目录，并可再次运行选择 U 更新或 R 删除。

## 使用

1. 运行助手。
2. 选择游戏本体 EXE，例如 Cyberpunk 2077 的 `bin\\x64\\Cyberpunk2077.exe`。
3. 点击“一键安装到此游戏”。内置 DLL 会自动释放和校验。助手会下载官方安装器并验证 SHA-256，然后把准备文件放入该游戏目录并启动官方安装器。
4. 按官方安装器提示完成；启动游戏，启用 FSR，按 End 调出菜单。
5. 官方安装器已经启动后，更新/删除请再次运行官方安装器并按 U/R。助手的“恢复助手文件”仅恢复它在官方安装器启动前写入的两份文件。

助手不会绕过反作弊、签名校验或游戏保护，也不会把网络下载的未知文件直接写入游戏目录。
