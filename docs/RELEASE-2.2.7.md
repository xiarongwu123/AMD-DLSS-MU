# AMD DLSS MU v2.2.7

## 新增：60系显卡专用

- 新增高级会员方案「60系显卡专用」，固定使用 Daniel 0.6.0，适用于 AMD RX 6000（RDNA2）。
- 当前 MU 接入条件为 Windows 11、HIP 7.2、64位 DX12 游戏。配置时打开 Daniel 0.6.0 官方安装窗口，需要在窗口中确认游戏并完成安装，MU 随后检查文件与安装记录。
- **受显卡性能限制，无法保证帧率表现和游戏兼容性。** 文件部署完成不等于神经渲染已经在游戏内生效。
- 会员权限在界面、配置请求与安装重试中均会检查，安装记录保留方案标识，可使用恢复配置。

## 修复：配置与模型准备

- 修复便携 Python 隔离环境下，作者调校版模型提取脚本找不到配套模块的问题。
- 修复已确认的游戏接口未完整传入实际安装及重试流程，仍提示接口未知的问题。
- 修复手动修改 NR 后端后，前置检查仍按默认后端判断的问题。
- 修复 Daniel 分支将尚待释放的内置 DLL 误判为必须自行导入的资源。
- 修复手动配置受保护联机环境时，在风险确认前直接被拦截的问题；继续配置仍须知悉风险，MU 不绕过反作弊，自动推荐及明确禁用规则仍保持限制。
- 模型提取失败保留退出码、详细输出和诊断日志，便于定位原因。

## 优化：界面响应与任务状态

- 游戏库状态改为缓存，下载进度等状态单独更新，减少每300毫秒重复读取安装记录、处理和传输全部封面的开销。
- 喜鹊启动进度绑定对应任务；启动失败会返回错误，不再误显示已完成。
- 工具已打开的任务可正确归入已完成列表；修复部分异步重试异常处理。
- 配置完成回执使用「已部署」描述，启动游戏期间防止重复点击。

## 其他修复

- 修复账户令牌并发写入使用同一临时文件的问题。
- 修复玩家方案参数大小写处理不一致、附件保留文件名检查等边界问题。
- 修复下载任务结束后延迟回调继续更新状态的问题。
- 纳入此前本地构建中的 MU-AMD-DLSS5 效果组迁移；本轮未再次调整喜鹊效果链和运行库。
