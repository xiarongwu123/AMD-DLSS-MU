# 32位游戏神经渲染桥接（实验性）

MU 客户端继续使用64位程序。游戏程序由PE机器类型识别；32位游戏使用模式ID 5，不改变原有0/2/4模式和旧恢复记录。

## 组件与来源

安装结构参照 zmodelerlover/AMD-NR-ReShade-Installer 的提交 `613e0f30ad6a6b043c97e4d02fc93532141da843` 中 payload/payload.json。
固定配套版本：桥接0.7.12、神经渲染运行库0.6.0、ReShade32全插件版6.8.0。此桥接版本号与 Daniel 的0.7.0新运行库无关。

桥接包含 amd-nr.addon32、amd-nr-host64.exe、dlssnr_amd_pass1.dll、模型数据与32位ReShade。DX8额外使用固定版本d3d8to9。每个文件下载前有固定长度和SHA256，缓存、安装前及复制后均校验。

## 使用

画质优先自动匹配桥接。支持实验性DX8、DX9、DX10/11、OpenGL，PE导入表无法唯一确认时由用户在界面选接口。游戏内Home打开ReShade，Ctrl+End切换神经渲染；初次配置启用StartOn，画质参数沿用上游默认。

需要AMD HIP 7，RX6000继续使用现有HIP7.2安装流程。反作弊继续使用现有知悉风险确认，不会关闭或绕过反作弊。

这条路线提供神经渲染，不提供XeFG。现有64位玩家方案不能用于32位桥接，桥接配置上传暂未接入。

## 恢复与限制

全部组件进入MU恢复记录。已有其他插件、配置或代理DLL时不会直接覆盖；配置失败回退本次修改。运行后INI变化按现有保留配置的恢复流程处理。

本机是macOS：已用真实固定组件验证安装、诊断文件完整性、恢复及再次安装；不能据此宣称已在Windows游戏内验证兼容性或性能，尤其是RX7000。
