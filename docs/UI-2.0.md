# MU 2.0 UI 重构

UI 起始分支：`codex/v2-ui-refactor`，起点：`main` / `48c80e8`。
账号接入分支：`codex/account-membership`；版本：`2.0.0-preview.2`；文件版本：`2.0.0.1`。

## 设计基准

- [Figma 设计文件](https://www.figma.com/design/GLtlmZPJiM5Iv8KNxb8BXR)
- 首页、游戏库与 Hover：画板 34、35、36；连续滚动原型节点 `5:2523`。
- 登录、注册：节点 `39:9292`、`39:9395`，官网风格。
- 主色：背景 `#05080D`、面板 `#0B111A`、描边 `#233041`、强调 `#ADFF18`。
- 实现继续使用 .NET 8 WinForms。中文字体使用 Windows 可用的 Microsoft YaHei UI；技术标签使用 Consolas。字体不是 Figma 中 Noto Sans SC / Rajdhani 的完全相同字形。

## 已实现的行为

- 顶部固定导航、搜索、更新与账户入口；移除侧栏。
- 首页四列，向下滚动进入游戏库；导航可以定位首页或游戏库。
- 首页显示本机扫描到的前四个游戏，空位显示添加入口，计数来自实际数据。
- 游戏库按四列、两行、每页最多八个游戏分页；最后一页不伪造数据。
- 全部、已配置、未配置、需确认筛选；搜索或更换筛选重置页码，页码越界自动收敛。
- 封面顶对齐裁切；悬停显示 HUD 操作层和“开启 DLSS5”，离开恢复封面。
- 操作按钮进入配置面板，沿用现有模式选择、兼容性确认、下载校验、恢复与诊断流程。
- 开始配置后转到下载任务，避免模态窗口挡住暂停和取消入口。
- 邮箱验证码注册、密码登录、找回密码、账户中心、修改密码与退出；勾选保持登录后使用 Windows DPAPI 保存刷新令牌。
- 启动在线验证后进入业务，每 30 秒检查会话；新操作查询对应功能权限。断网或会话失效禁止新操作，已开始的文件写入事务安全收尾。
- 移除游客入口及未实现的云同步、云备份宣传。后端和管理后台位于同仓 `server/`，部署与验收说明见 [server/README.md](../server/README.md)。

## 明确未完成的集成

- 生产公开注册在 Resend 域名、发送密钥和真实收信验证完成前关闭。支付仅预留接口、订单与流水数据，购买入口关闭。
- Figma 示例游戏和显卡信息不作为真实扫描数据展示。
- 新账号版客户端需完成 Windows 实机验收后再替换官网公开下载。当前工作区已具备发布必需的 `assets/nvngx_dlssnr.dll`。
- Mac 无法运行 WinForms 界面；编译和逻辑测试不代表 Windows 视觉、DPI 或游戏运行验证完成。

## 验证方式

```sh
dotnet build tests-ui/Ui.Compile.csproj
dotnet run --project tests-account/Account.Tests.csproj
TMPDIR=/private/tmp dotnet run --project tests/Management.Tests.csproj
TMPDIR=/private/tmp dotnet run --project tests-update/ReleaseValidation.csproj
```

`tests-ui` 仅编译全部 UI 源码，不内置游戏运行时，不可作为发布包；正式项目的 DLL 必需校验保持不变。

macOS 验证包含 UI 编译、账号 HTTP 测试、管理/下载/分页/Magpie 测试及更新版本校验。SDK 使用项目外 `/Volumes/SamsungPSS/mu/.tools/dotnet-8/dotnet`；本次结果另见账号交付记录。

Windows 验收：

1. 1440×910 和最小窗口、100%/150%/200% DPI 下检查导航、表单、四列布局、滚动及文本裁切。
2. 分别使用 0、3、8、9、16、17 个游戏测试空态、两行分页和最后一页。
3. 在最后一页搜索或切换筛选；添加新游戏后确认卡片定位及计数刷新。
4. 鼠标进入封面、移出、键盘选择卡片，确认操作层出现并可以进入配置面板。
5. 配置两个安装模式，分别检查下载暂停/取消/失败重试、恢复和诊断入口。
6. 真实验证码注册、无效/过期验证码、发送限流、密码找回、改密、退出及重启保持登录；不保持登录时不得保存凭据。
7. 登录后确认既有手动游戏、设置、安装记录和恢复数据仍可使用；未登录时按钮、键盘、拖放、下载重试、F8 独立面板均不可绕过授权。
8. 后台变更功能等级、禁用账号、Pro 到期及断网后，新操作被拒绝；已进入文件写入的安装、恢复或更新完成安全收尾，已启动游戏不被终止。
