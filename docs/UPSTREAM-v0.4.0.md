# DLSS-NR on AMD v0.4.0 接入

官方发布：https://github.com/danielblnc/DLSS-NR-on-AMD/releases/tag/v0.4.0

- 安装器：`dlssnr_on_amd_setup.exe`
- 文件大小：`13183488` 字节
- SHA-256：`2d37453e918a1c5487314b3ae7c088b624ac0be1b82469427ec04b481a845ded`
- 依然要求用户提供 `nvngx_dlssnr.dll` 310.8.0.0；不代表新增 NVIDIA 显卡支持。

## 安装流程变化

上游已改为图形化安装器，官方说明没有公开静默安装参数。客户端不再重用 v0.3.1 控制台输入协议，也不会猜测参数、自动忽略警告或隐藏一个需要操作的安装窗口。

客户端校验下载内容后，在所选游戏 EXE 目录启动官方窗口。用户需核对目标 EXE 并完成安装，然后关闭窗口。客户端等待退出并检查游戏目录中的 DLL、代理、配置与权重文件，未完成安装不能标记成功。取消或等待超时会终止安装器，后续恢复沿用现有事务和备份机制。

## 验证范围

已核对官方 GitHub 资源元数据与实际下载文件哈希；管理回归测试覆盖版本锁定、旧版拒绝、资源被替换的拒绝和新版启动参数。UI 编译不能代替 Windows 实机验收。

Windows 上需验证：首次安装、多个 EXE 时选择游戏本体、直接关闭窗口、取消、AMD HIP 缺失、正常完成后已配置即时更新、恢复原配置。必须使用支持的 AMD 显卡进入游戏，开启 FSR 并用 End 菜单验证运行效果。
