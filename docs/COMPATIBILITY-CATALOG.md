## 数据与实测分离

目录不会生成 `CompatibilityTests`。没有真实实测的游戏继续显示“待验证”。商店发行日期不是游戏构建版本；NVIDIA 列表收录不是 MU/DLSS5 在 AMD 显卡上的成功证明。客户端主动上报仍是实测数据来源。

目录 JSON 嵌入服务发布文件，按 Steam AppID 幂等导入。新条目使用稳定的 `steam-{AppID}` ID；原有四款游戏及已上报游戏保留原 ID，更新官方名称和检索文字时不删除报告或修改用户数据。来源详情按同一个 AppID 从嵌入快照读取；身份数据库 schema 保持 3。

## 查询与展示

官网支持中英文名称、原有别名、Steam AppID，以及显卡筛选。搜索接口添加 `page` / `pageSize`，返回 `total`、`page`、`pageSize`、`catalogTotal`；默认 1 / 50，上限 50。排序为名称后 ID，防止同名游戏跨页重复。旧客户端仍能读取 `items`。

网页每页 20 款，可前后翻页、输入页码跳转，查询链接包含页码与筛选。详情先展示可追溯的官方资料，再展示 MU 玩家实测；网页代理校验来源网址、游戏身份、总数和分页元数据。
