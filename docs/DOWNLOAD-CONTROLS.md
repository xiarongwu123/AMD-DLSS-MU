# 一键配置下载控制

- 游戏配置弹窗在下载及连接阶段直接显示暂停/继续、取消，不必先跳转到下载任务页。
- 关闭配置弹窗或点击“收起并后台继续”只收起界面，任务继续运行，可在下载任务查看。新打开的配置按钮仍遵守全局安装锁，不能重复安装。
- DownloadSession允许在连接阶段暂停，发请求前等待继续；流式传输每块读取前也等待。已有HTTP请求中的单次读操作可能完成后才停住，暂停不表示立即中断网络套接字。
- 取消已暂停的下载会解除等待并结束任务。已下载分段按固定SHA256保留，用于后续安全续传。
- 主窗口在下载阶段收到关闭请求时，先取消下载，最多等待30秒安全收尾，再关闭。正在校验/部署/恢复时继续保护文件写入，可先最小化；不强行结束进程。
- 模型提取及文件写入不属于可暂停下载阶段，不显示暂停按钮。

普通版及测试版的NVIDIA硬件放行代码已移除；原独立N卡大力喜鹊入口不受影响。旧的NVIDIA流程测试EXE是单独产物，不会通过本次源码修改自动失效，应停止使用旧测试包。

验证覆盖连接前暂停、重试状态保留暂停、继续、暂停后取消、校验阶段不能暂停，以及配置弹窗中的控制与收起。Windows窗口实际关闭行为待真机验证。
