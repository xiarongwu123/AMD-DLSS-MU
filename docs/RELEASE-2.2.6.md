# AMD DLSS MU v2.2.6

> 套餐 CDK 新流程需要配套更新后台。客户端 Release 不会自动部署服务器；旧后台会显示更新提示，避免兑换出错误套餐权益。

## 付款后兑换 CDK

- 选择套餐后，按钮改为「支付完成 校验CDK」。
- 支付成功后添加微信 **xrwCoder**，发送付款凭证与所选套餐，人工核对后获取对应 CDK。
- 服务端核对兑换码与套餐，兑换成功自动刷新会员及服务权益；不匹配不会消耗兑换码。
- 支持月会员、终身会员、Plus 和单次远程指导套餐；套餐权益以发码时的快照为准。
- 旧的普通高级会员天数码继续保留，不能兑换为终身、Plus 或指导次数。
- 不再通过新版套餐页创建付款申请或提交付款声明；付款本身不会自动开通。

## 配置下载控制

- 一键配置弹窗直接提供暂停、继续、取消下载。
- 连接阶段也可暂停；取消已暂停任务可以正常结束。
- 关闭配置弹窗可收起并在后台继续，在下载任务页查看进度。
- 下载中关闭主窗口，会先请求取消并等待安全收尾；校验、部署或恢复期间继续保护文件写入。

## 作者调校版资源准备

- 本地模型缓存缺失或校验失败时，可从内置配套资源重新提取并核验。
- 新模型先在临时目录生成，校验成功后备份、替换缓存；失败保留原文件。
- 为固定版本资源包增加官方 GitHub Asset API 下载备用源，继续保留版本、大小与 SHA256 校验。

## 其他

- 移除内部 NVIDIA 安装流程测试放行，恢复正常 GPU 检查。
- 现有安装记录、恢复能力、会员权限及独立大力喜鹊入口保留。

## 部署与下载

后台管理员更新服务后，进入 `/admin/codes` 选择对应套餐发码。后台启动会保留旧码并追加套餐快照字段；先备份数据库与 DataProtection 密钥，按配套部署说明操作。

- `AMD-DLSS-MU.exe`：Windows x64 自包含程序，界面需要 WebView2。
- `AMD-DLSS-MU-2.2.6-Windows-x64.zip`：同一程序及使用说明。
- `SHA256.txt`：文件校验值。

前端、账户客户端、模型/下载回归、后台服务、HTTP 和管理员测试通过；Windows 交叉发布构建通过。本次 EXE 尚未在 Windows 真机运行验证，配置成功不等于游戏内神经渲染已经生效。
