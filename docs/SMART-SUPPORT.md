# MU 右下角智能客服

## 当前交付

右下角「遇到问题？智能客服」打开非模态排错面板。用户粘贴报错或输入问题，本地检索 39 条经过整理的用户知识记录，展示可能原因、步骤、人工升级条件和知识来源。支持组合错误码、常见中文描述、复制记录、清空对话、微信联系。输入最多 4000 字符，内存最多保留最近 12 次查询；刷新或退出后不保存。

这是知识库检索版本，没有接入大模型，不进行多轮语义推理，不上传问题或读取本机日志。未知问题明确要求用户补充信息。公开知识库不包含付费游戏名单、私人游戏参数、管理员 CDK 操作、动态套餐价格。

## 维护

- 数据：`desktop-ui/src/support/knowledge.json`
- 检索与别名：`desktop-ui/src/support/search.ts`
- 界面：`desktop-ui/src/ContactFloat.tsx`
- 知识基线：MU 2.2.4，复核日期 2026-10-26。更新组件/资源/规则时同步复核答案和版本。
- 完整错误码优先匹配。普通描述按标题、关键词与别名检索，低匹配度返回未知，不生成未经证实的解决方案。
- 可复制内容仅为用户输入与已显示的建议。转人工由用户自行发送。

## 后续接入大模型

如需要自由问答，应增加服务端模型代理和授权检查，把命中的知识片段作为依据返回。模型密钥不得放在 React 或 EXE；会员限额在服务端执行。服务未配置或请求失败时保留本地检索，明确标注来源。日志上传需用户明确选择，先脱敏，不自动上传账户令牌、个人路径、付费名单。
