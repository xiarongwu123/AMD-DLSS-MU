# AMD大力喜鹊一键打开修复

## 已确认原因

1. 下载目标本来就是包含运行库与模型的上游完整包，但启动器在下载前要求用户选择资源目录，首次使用无法完成。
2. 游戏方案入口在打开外部程序前执行了GPU、窗口模式和资源完整性推荐检查；大力喜鹊页面入口没有相同检查，导致两个入口行为不同。
3. 源码标签与实际发布二进制使用不同运行库哈希。MU旧哈希来自源码；真实完整包中的运行库被错误拒绝。完整包SHA256仍保持原固定值。
4. A卡进度写入主窗口状态，没有同步到React读取的`magpieStatus`，页面可能继续显示之前N卡启动的旧错误。
5. 已存在但残缺的安装没有重建路径；可编辑INI作为不可变文件校验，也会把用户调整误判为组件损坏。

## 新流程

点击A卡按钮 → 验证高级权限与Windows x64 → 复用完整安装或下载固定完整包 → 校验SHA256与原生组件 → 准备便携配置 → 再次核验权限 → 打开AMD Magpie。

不再弹资源目录选择框，不要求选择游戏或先确认窗口模式。开启效果时仍需在工具中选择实际目标窗口与效果。RX6750等未验证显卡能够进入独立工具，不等同于确认其神经渲染效果可用。

修复安装采用新暂存目录，保留旧目录备份，复制用户配置与INI后切换。失败不会自动删除原目录；取消或失败可重试。会员权限、下载固定版本与哈希、独立目录、原游戏文件不被改动等检查保留。
