# MU 账号系统交付记录

日期：2026-09-26。开发分支：`codex/account-membership`。

## 已实现

- .NET 8 WinForms 客户端接入邮箱验证码注册、密码登录、找回/修改密码、退出、DPAPI 保持登录和账户中心。
- 启动必须验证登录；每 30 秒检查会话，业务操作实时授权。按钮、键盘、拖放、下载重试/续传及独立面板均接入权限检查。
- 普通/Pro、会员期限及固定功能权限由服务端决定。失联禁止新操作；已经进入游戏文件写入的事务完成安全收尾。
- .NET 10 API、Identity、独立 SQLite 数据库及 Razor 管理后台同仓维护。管理员独立 Cookie、TOTP、CSRF、实时身份撤销及操作审计。
- 后台管理用户、会话、人工 Pro 授权、套餐、订单及功能权限。功能配置有独立递增版本，规则与前后版本审计同事务保存。支付适配器只包含禁用实现，无虚假付款成功路径。
- 注册、验证码发送、密码重置均使用 Resend 适配器，未配置时明确失败；日/月额度耗尽、限流和一般发送失败分别提示。生产注册与支付默认关闭。
