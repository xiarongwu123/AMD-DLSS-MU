# 贴吧发帖文案

推荐标题：自己做了个游戏配置工具 MU，整合三种方案，现在还能查显卡和游戏配置

备选标题：
- 折腾 DLSS-NR / OptiScaler 的吧友看过来，做了个统一配置工具
- MU v2.0.2 更新：加入游戏兼容库，大力喜鹊支持镜像下载

正文：

最近一直在做一个 Windows 游戏图形配置工具，叫 AMD DLSS MU，目前更新到 v2.0.2 正式版，发来给有需要的吧友试试。

主要想解决一个问题：折腾不同图形方案时，下载组件、找游戏目录、管理配置、恢复文件这些步骤太零散。所以把常用入口集中到一起，尽量少点重复操作。

目前主要能做这些：

1. 游戏库管理：扫描常见游戏目录，也能手动添加，按游戏管理配置。
2. 三种方案入口：DLSS-NR、OptiScaler、大力喜鹊，按游戏和硬件条件选择。
3. 配置恢复：配置前记录原始文件状态，恢复时核验文件变化。
4. 显卡与游戏资料查询：官网可查 2,000+ 款游戏的官方配置，填写显卡、CPU 和内存后查看硬件参考，还能查 OptiScaler 上游适配资料。客户端登录后也能搜索游戏、按显卡筛选已有记录。
5. 大力喜鹊镜像下载：优先走自有镜像，保留文件校验，镜像不可用时自动回退。

它是独立第三方配置工具，实际效果取决于具体游戏、显卡和驱动。配置参考不代表 MU / DLSS5 已实测兼容，DLSS-NR 上游安装器里的部分步骤仍需手动完成。

官网和下载：https://amd-dlss-mu.claude-api.cn/
配置查询：https://amd-dlss-mu.claude-api.cn/compatibility

有相关使用需求的吧友可以试试。遇到问题可以带上显卡型号、游戏名和具体表现，方便定位；也欢迎说说哪些操作最麻烦，后面继续改。
