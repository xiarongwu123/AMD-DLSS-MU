Generated using the `codex-gpt-image` skill with the user's explicit approval to use Codex subscription OAuth after the configured API-key provider was unavailable. Artwork is illustrative branding, not a measured performance comparison or an indication that DLSS is currently active.

Both assets are embedded in `AmdNrAssistant.csproj`; they are not downloaded at runtime. Original account and Magpie backgrounds are retained for their existing pages.
