REQUIREMENTS

使用条件

  • Windows 11；使用 DirectX 12、支持 FSR 3／FSR 4 的游戏。
  • RX 7000 系列兼容性与性能需实测。
  • 不要用于带反作弊的联网游戏。
02

INSTALL

安装步骤（模式一）

  1. 关闭游戏，在启动器中选中游戏；扫描不到时点击「添加游戏」。
  2. 选择「模式一」→「一键配置」。v1.3.3 已内置 DLL，无需另行下载。
  3. 按黑色安装窗口提示确认游戏目录和 EXE，等待安装完成；文件冲突时不要直接覆盖。
  4. 启动游戏，开启 FSR 3／FSR 4 超分辨率，不能只开帧生成。
  5. 进入实际游戏场景，按 End 打开面板。
效果验证游戏设置里不一定出现「DLSS 5」；安装完成不代表效果已验证。

FAQ

常见问题

  • End 没反应：确认安装完成、FSR 已开启；仍无效时提交「导出诊断」文件及游戏目录中的 dlssnr_on_amd.log（如有）。
  • 严重卡顿或闪退：退出游戏，点击「恢复配置」，不要重复叠加安装。
  • 下载失败：程序会尝试官方备用入口；仍失败时稍后重试，并提供错误截图。
