事件触发时机用于判断
page_view同意统计后页面进入，每次加载一次浏览量、会话、来源
session_heartbeat页面可见时每 60 秒；只更新活跃时间近 5 分钟活跃会话
download_click点击直接下载按钮下载入口的交互意图
download_request / download_redirect服务器开始传输完整文件或首段；兼容历史跳转版本下载请求及会话转化
feedback_start首次填写反馈表单反馈填写意图
feedback_accepted / rejected反馈保存成功或校验失败提交质量与问题分布
hash_copy成功复制 SHA-256校验功能使用情况
release_published / publish_failed版本配置写入成功或失败发行操作审计
feedback_status_changed管理员改变反馈状态问题处理进展
admin_login_failed管理员密码验证失败异常登录信号

客户端下一阶段

建议增加软件启动、兼容性检查、组件安装/恢复结果、升级结果和结构化错误。当前 EXE 未接入，暂不展示活跃用户、安装成功率、留存率或自动测得的 FPS。

客户端应提供独立的匿名统计开关，仅上传软件版本、受控错误码、操作耗时与必要环境分类。游戏路径、账号、原始日志和硬件序列号不进入埋点。

统计边界

  • 匿名会话按 30 分钟有效期划分，不是独立人数；拒绝统计的访问不计入会话转化。
  • 已登录管理员、常见机器人和 HEAD 检查请求不计入访问与下载；过滤无法识别所有自动流量。
  • GitHub 累计下载来自官方接口，包括从其他渠道直接下载，不代表下载完成、安装成功或官网下载人数。
  • 匿名事件明细保留 90 天，接口耗时明细保留 14 天；反馈及处理状态持久保存。
